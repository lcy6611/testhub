# AI 测试模块 - 依次进行说明

按以下顺序使用，可走通完整业务流（项目管理 → 套件 → 用例执行 → 定时任务 → 通知）。

---

## 新页面报错（加载套件失败 / 加载任务列表失败 / 服务器错误）

**原因**：AI 相关数据库表未创建，后端访问 `ui_ai_suites`、`ui_ai_scheduled_tasks`、`ui_ai_notification_logs` 时会报 500。

**解决**：在项目根目录执行一次迁移：

```bash
# Windows CMD / PowerShell（在项目根目录）
python manage.py migrate

# 若使用虚拟环境，先激活再执行
# Windows: E:\python_venv\testhub\Scripts\activate.bat
# 然后: python manage.py migrate
```

确认 `ui_automation` 的迁移已应用（包含 `0006_ai_suite_scheduled_notification`）。执行完成后刷新页面即可。

---

## 1. 项目管理（入口）

- **路径**：`/ai-intelligent-mode/projects`
- **操作**：
  - 新建项目（名称、描述、状态、基础 URL、日期）
  - 编辑 / 删除项目
  - 点击 **「用例」** → 跳转到 AI 用例管理并带 `?project=项目ID`
  - 点击 **「套件」** → 跳转到 AI 套件管理并带 `?project=项目ID`

---

## 2. AI 用例管理

- **路径**：`/ai-intelligent-mode/cases`
- **说明**：若从项目管理带 `project` 入参，列表会按该项目筛选用例。
- **操作**：
  - 新建 / 编辑 / 删除 AI 用例（名称、描述、任务描述）
  - **执行**：点击「执行」→ 弹窗选择 **执行模式**（自动/文本/视觉）和 **有头/无头**、GIF 录制 → 开始执行后跳转到「AI 执行记录」

---

## 3. 套件管理

- **路径**：`/ai-intelligent-mode/suites`
- **说明**：仅包含 **AI 用例**，无脚本；需先选项目。
- **操作**：
  - 选择项目（若从项目管理跳转会带 `?project=id` 自动选中）
  - 新增套件：名称、描述、从当前项目下多选 AI 用例
  - 编辑套件：修改名称、描述、已选用例
  - **运行套件**：弹窗选择执行模式、有头/无头 → 按顺序执行套件内所有 AI 用例，完成后可在「AI 执行记录」查看

---

## 4. AI 执行记录

- **路径**：`/ai-intelligent-mode/execution-records`
- **操作**：查看单用例或套件执行记录、报告、GIF 回放等。

---

## 5. 定时任务

- **路径**：`/ai-intelligent-mode/scheduled-tasks`
- **操作**：
  - 新建：选择项目、任务类型（**AI 套件执行** 或 **AI 用例执行**）、对应套件或用例
  - 触发类型：Cron / 间隔 / 单次
  - 执行模式、无头模式、成功/失败通知
  - 编辑、暂停、恢复、立即执行、删除

---

## 6. 通知列表

- **路径**：`/ai-intelligent-mode/notification-logs`
- **操作**：查看 AI 定时任务触发的通知记录，支持按任务名称搜索、查看详情。

---

## 与 UI 自动化的差异（简要）

| 能力           | UI 自动化           | AI 测试                 |
|----------------|---------------------|-------------------------|
| 套件内容       | 用例 + 脚本         | 仅 AI 用例              |
| 执行参数       | 引擎/浏览器/无头    | 执行模式 + 有头/无头    |
| 定时任务类型   | 测试套件/测试用例   | AI 套件/AI 用例         |

按 **1 → 2 → 3 → 4 → 5 → 6** 依次进行即可验证整条链路。
