# 安装与部署

适用于需要在自有环境搭建 TestHub 的运维人员。

## 环境要求

- Docker & Docker Compose
- MySQL 5.7+
- Redis 6+

## 启动开发环境

```bash
# 克隆仓库后，在项目根目录执行
docker compose -f docker-compose.dev.yml up -d

# 查看前端日志
docker logs testhub_dev-frontend-1 -f
```

启动后访问：

- 前端： http://localhost:5173
- 后端 API： http://localhost:8000/api

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `./start_dev.sh` | 一键启动开发环境 |
| `docker compose down` | 停止并清理容器 |

## 注意事项

1. 首次启动请确保 MySQL 已初始化且网络可达
2. 文档中心扫描的是 `docs/docs-center/` 目录下的 Markdown 文件
3. 修改后端代码后 Django 热重载，无需手动重启
