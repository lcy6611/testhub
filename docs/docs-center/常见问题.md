# 常见问题（FAQ）

汇总使用 TestHub 时的高频疑问。

## 登录与权限

**Q：登录后提示无权限？**
A：请联系管理员将你加入对应项目的成员列表。

**Q：Token 过期频繁？**
A：默认访问令牌 5 分钟内自动刷新，若仍频繁过期请检查系统时间同步。

## 用例生成

**Q：生成的用例质量不高？**
A：建议先完善需求文档的标题层级与示例，并补充功能点描述。

**Q：支持哪些文档格式？**
A：当前支持 Markdown（`.md`）与 Word（`.docx`）。

## 执行相关

| 现象 | 排查方向 |
| --- | --- |
| 执行无响应 | 检查执行器容器是否启动 |
| 报告为空 | 确认用例已关联测试套件 |

```bash
# 查看后端容器日志
docker logs testhub_dev-backend-1 --tail 100
```
