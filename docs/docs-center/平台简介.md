# TestHub 平台简介

TestHub 是一站式测试效能平台，覆盖从需求、用例、执行到报告的全链路测试活动。

## 核心能力

- **AI 智能用例生成**：基于需求文档自动生成测试用例
- **接口 / UI / APP / 性能自动化**：多类型自动化测试统一管理
- **知识中枢**：文档、知识库与图谱一体化的智能检索
- **文档中心**：本模块，集中托管平台使用文档（你正在看的页面）

## 适用角色

| 角色 | 主要用途 |
| --- | --- |
| 测试工程师 | 编写用例、执行测试、查看报告 |
| 测试经理 | 项目概览、评审与门禁 |
| 运维 | 环境管理、日志与文件传输 |

## 快速导航

```bash
# 本地开发启动（示例）
./start_dev.sh
```

> 提示：左侧目录树支持多级子目录，点击任意文档即可在右侧阅读。
