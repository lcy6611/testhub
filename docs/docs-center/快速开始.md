# 快速开始

本文带你 5 分钟跑通 TestHub 最常用的流程。

## 第一步：创建项目

进入「AI 用例生成 → 项目管理」，点击新建项目并填写基本信息。

## 第二步：导入需求

在项目中上传需求文档（支持 `.docx` / `.md`），系统会自动解析结构。

## 第三步：生成用例

点击「AI 生成」，选择生成策略：

1. 选择目标需求
2. 设置覆盖维度（功能 / 异常 / 边界）
3. 提交并等待生成完成

## 第四步：执行与查看报告

```python
# 伪代码示例：调用执行接口
response = client.post("/api/executions/", json={
    "project_id": 1,
    "suite_ids": [10, 11],
})
print(response.json()["run_id"])
```

完成后在「测试报告」中查看通过率与失败诊断。

## 常见问题

如遇到生成为空，请优先检查需求文档是否包含可解析的标题层级（如 `# 一级标题`）。
