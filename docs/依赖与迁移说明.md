## 四、可选：锁定关键版本（推荐）

若希望环境更可复现，可在 `requirements.txt` 中为本次升级被带动的包做版本锁定（可选）：

```text
# 与 browser-use 0.11.5 一起升级的，可按需锁定
# pydantic>=2.11.5
# pydantic-core>=2.41.5
# aiohttp>=3.13.3
# typing-extensions>=4.12.2
```

未锁定也不影响当前运行；锁定后便于将来复现同一环境。
